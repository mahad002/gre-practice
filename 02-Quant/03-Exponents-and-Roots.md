# Exponents and Roots

Exponent and root questions reward people who know a short list of rules cold. They are common in Quantitative Comparison, where the test checks whether you remember how fractions, negatives, 0 and 1 behave under powers.
Study plan (about 2 days): day 1 = read sections 1 to 3 and do practice 1 to 10. Day 2 = practice 11 to 25, then review every problem you missed or guessed.

## 1. What you must know

**Exponent rules**

1. Same base, multiply: add exponents. a^m * a^n = a^(m+n). Example: 2^5 * 2^3 = 2^8.
2. Same base, divide: subtract exponents. a^m / a^n = a^(m-n). Example: 2^8 / 2^6 = 2^2 = 4.
3. Power of a power: multiply exponents. (a^m)^n = a^(mn). Example: (2^3)^4 = 2^12.
4. Same exponent: (ab)^n = a^n * b^n and (a/b)^n = a^n / b^n. Example: 6^4 = 2^4 * 3^4.
5. Zero exponent: a^0 = 1 for any a that is not 0. Example: (-7)^0 = 1.
6. Negative exponent: a^(-n) = 1/a^n. It flips the number. It does not make it negative. Example: 2^(-3) = 1/8, and (2/3)^(-2) = (3/2)^2 = 9/4.
7. Fractional exponent: a^(m/n) = (n-th root of a)^m. Take the root first to keep numbers small. Example: 8^(2/3) = (cube root of 8)^2 = 2^2 = 4.
8. There is no rule for adding powers. a^m + a^n cannot be merged, but you can factor. Example: 2^10 + 2^10 = 2 * 2^10 = 2^11, and 2^(x+3) - 2^x = 2^x (8 - 1) = 7 * 2^x.
9. (a + b)^2 is not a^2 + b^2. Example: (3 + 4)^2 = 49 but 9 + 16 = 25.
10. Powers to memorise: 2^1 to 2^10 = 2, 4, 8, 16, 32, 64, 128, 256, 512, 1,024. 3^1 to 3^5 = 3, 9, 27, 81, 243. 5^1 to 5^4 = 5, 25, 125, 625. Squares from 11^2 to 20^2 = 121, 144, 169, 196, 225, 256, 289, 324, 361, 400. 25^2 = 625. Cubes 1, 8, 27, 64, 125, 216.

**Equations and comparisons**

11. Same-base equations: rewrite both sides with the same base, then set the exponents equal. Example: 9^x = 27^(x-2) becomes 3^(2x) = 3^(3x-6), so x = 6.
12. Useful base changes: 4 = 2^2, 8 = 2^3, 16 = 2^4, 32 = 2^5, 9 = 3^2, 27 = 3^3, 81 = 3^4, 25 = 5^2, 125 = 5^3.
13. Comparing powers: make the exponents equal (or the bases equal). Example: 2^30 vs 3^20 becomes (2^3)^10 vs (3^2)^10, which is 8^10 vs 9^10. So 3^20 is greater.
14. x^2 = 9 has two solutions, x = 3 and x = -3. An even power hides the sign. x^3 = -27 has one solution, x = -3.

**Signs, and numbers between 0 and 1**

15. Negative base: an even exponent gives a positive result, an odd exponent gives a negative result. Example: (-2)^4 = 16, (-2)^5 = -32.
16. -3^4 = -81 because the exponent applies only to the 3. (-3)^4 = 81.
17. If 0 < x < 1, higher powers are smaller: x^3 < x^2 < x. Roots are bigger: sqrt(x) > x. Example: (1/2)^2 = 1/4, and sqrt(1/4) = 1/2.
18. If x > 1, higher powers are bigger: x^3 > x^2 > x > sqrt(x).
19. If -1 < x < 0: x^2 is positive and less than 1, and x^3 is negative but closer to 0 than x. Example: x = -1/2 gives x^2 = 1/4 and x^3 = -1/8, so x < x^3 < 0 < x^2.
20. If x < -1: x^3 < x < 0 < x^2. Example: x = -2 gives -8 < -2 < 4.
21. For any QC question with powers of x, test these values: 2, 1/2, 0, 1, -1/2, -1, -2. They cover every zone of behaviour.

**Roots**

22. sqrt(x) means the non-negative root only. sqrt(16) = 4, never -4. And sqrt(x^2) = |x|. Example: sqrt((-5)^2) = 5.
23. Square roots of negatives are not real numbers. Odd roots of negatives are fine. Example: cube root of -8 = -2.
24. Multiply and divide: sqrt(a) * sqrt(b) = sqrt(ab), and sqrt(a)/sqrt(b) = sqrt(a/b). Example: sqrt(2) * sqrt(8) = sqrt(16) = 4.
25. No rule for adding: sqrt(a + b) is not sqrt(a) + sqrt(b). Example: sqrt(9 + 16) = 5, not 7.
26. Simplify by pulling out the largest perfect square. Example: sqrt(72) = sqrt(36 * 2) = 6 sqrt(2).
27. Add only like radicals. Example: sqrt(50) + sqrt(18) = 5 sqrt(2) + 3 sqrt(2) = 8 sqrt(2).
28. Rationalise a single root: multiply top and bottom by the root. Example: 6/sqrt(3) = 6 sqrt(3)/3 = 2 sqrt(3).
29. Rationalise a two-term denominator: multiply by the conjugate, using (a - b)(a + b) = a^2 - b^2. Example: 1/(3 - sqrt(2)) = (3 + sqrt(2))/(9 - 2) = (3 + sqrt(2))/7.
30. Values to memorise: sqrt(2) = 1.41, sqrt(3) = 1.73, sqrt(5) = 2.24. To estimate other roots, bracket between perfect squares. Example: sqrt(50) is just over 7.
31. To compare expressions with roots, square both sides (if both are positive). Example: sqrt(7) + sqrt(3) vs 4. Squares: 10 + 2 sqrt(21) vs 16. Since 2 sqrt(21) is about 9.2, the left side is greater.

**Scientific notation**

32. Form: a * 10^n with 1 <= a < 10. Example: 360,000 = 3.6 * 10^5 and 0.00042 = 4.2 * 10^(-4).
33. Multiply or divide the number parts and the powers of 10 separately, then fix the form. Example: (3.6 * 10^5)/(9 * 10^(-2)) = 0.4 * 10^7 = 4 * 10^6.
34. Counting digits: 10^n has n + 1 digits. Pair up 2s and 5s to make 10s. Example: 2^5 * 5^3 = 4 * 10^3 = 4,000.

**Units digits of powers**

35. Only the units digit of the base matters. Cycles: 2 -> 2, 4, 8, 6. 3 -> 3, 9, 7, 1. 7 -> 7, 9, 3, 1. 8 -> 8, 4, 2, 6. 4 -> 4, 6. 9 -> 9, 1. Bases ending in 0, 1, 5, 6 never change.
36. Divide the exponent by 4 and use the remainder as the position in the cycle. Remainder 0 means the 4th position. Example: 3^45: 45 = 4*11 + 1, so the units digit is 3.

**Factorials**

37. n! = n(n-1)(n-2)...(1). 0! = 1 and 1! = 1. Memorise: 3! = 6, 4! = 24, 5! = 120, 6! = 720, 7! = 5,040.
38. Cancel factorials instead of computing them. Example: 10!/8! = 10 * 9 = 90. In general (n+1)!/n! = n + 1.
39. Factor sums of factorials. Example: 8! + 7! = 7!(8 + 1) = 9 * 7!.
40. Trailing zeros of n! = number of 5s in its factorisation = n/5 + n/25 + n/125 + ... (integer parts). Example: 25! ends in 5 + 1 = 6 zeros.

## 2. Worked examples

**Example 1 (Multiple choice, one answer)**
(2^3)^4 * 2^(-5) / 4^2 =
(A) 2 (B) 4 (C) 8 (D) 16 (E) 32

Solution: Write everything in base 2. (2^3)^4 = 2^12. 4^2 = 2^4. Exponents: 12 - 5 - 4 = 3. 2^3 = 8.
The trap: (2^3)^4 is 2^12, not 2^7. Power of a power multiplies.
Answer: C.

**Example 2 (Quantitative Comparison)**
x > 0
Quantity A: sqrt(x)
Quantity B: x

Solution: Test the zones. x = 4: sqrt(x) = 2 < 4, so B is greater. x = 1/4: sqrt(x) = 1/2 > 1/4, so A is greater. x = 1: equal. The relationship changes.
The trap: testing only integers greater than 1 and choosing B.
Answer: D.

**Example 3 (Numeric entry)**
27^(2/3) * 16^(-3/4) = ? Give the answer as a fraction.

Solution: 27^(2/3) = (cube root of 27)^2 = 3^2 = 9. 16^(-3/4) = 1/(fourth root of 16)^3 = 1/2^3 = 1/8. Product = 9/8.
The trap: treating the negative exponent as a negative number (answering -72 or -9/8).
Answer: 9/8.

**Example 4 (Multiple choice, one answer)**
If 2^(2x+1) = 8^(x-1), what is the value of x?
(A) 1 (B) 2 (C) 3 (D) 4 (E) 5

Solution: 8 = 2^3, so the right side is 2^(3x-3). Set exponents equal: 2x + 1 = 3x - 3, so x = 4. Check: 2^9 = 512 and 8^3 = 512.
Fastest method: back-solve from the options if you are unsure of the algebra.
The trap: writing 8^(x-1) as 2^(3x-1). The 3 multiplies the whole exponent.
Answer: D.

**Example 5 (Quantitative Comparison)**
Quantity A: 2^60
Quantity B: 5^25

Solution: The calculator overflows, so match the exponents. The GCD of 60 and 25 is 5. 2^60 = (2^12)^5 = 4,096^5. 5^25 = (5^5)^5 = 3,125^5. Since 4,096 > 3,125, A is greater.
The trap: choosing B because 5 is the bigger base, or A because 60 is the bigger exponent, without doing the work.
Answer: A.

**Example 6 (Multiple choice, one answer)**
sqrt(48) - sqrt(12) + sqrt(75) =
(A) sqrt(111) (B) 5 sqrt(3) (C) 7 sqrt(3) (D) 11 sqrt(3) (E) 21

Solution: sqrt(48) = 4 sqrt(3). sqrt(12) = 2 sqrt(3). sqrt(75) = 5 sqrt(3). Total: (4 - 2 + 5) sqrt(3) = 7 sqrt(3).
Fastest check: estimate. 6.93 - 3.46 + 8.66 = 12.12, and 7 * 1.73 = 12.11.
The trap: sqrt(48 - 12 + 75) = sqrt(111). You cannot add under the root.
Answer: C.

**Example 7 (Select all that apply)**
If x^3 < x < x^2, which of the following could be the value of x?
(A) -3 (B) -3/2 (C) -1 (D) -1/2 (E) 1/2 (F) 2

Solution: Test each. x = -3: -27 < -3 < 9, true. x = -3/2: -3.375 < -1.5 < 2.25, true. x = -1: -1 < -1 is false. x = -1/2: -0.125 < -0.5 is false. x = 1/2: 0.5 < 0.25 is false. x = 2: 8 < 2 is false. The pattern x^3 < x < x^2 is the zone x < -1 (rule 20).
The trap: stopping after finding one answer. Select-all questions can have several.
Answer: A and B.

**Example 8 (Multiple choice, one answer)**
What is the units digit of 2^75?
(A) 0 (B) 2 (C) 4 (D) 6 (E) 8

Solution: Powers of 2 cycle 2, 4, 8, 6. 75 = 4*18 + 3, so use the third digit: 8.
The trap: when the remainder is 0 (for example 2^76), the digit is the last in the cycle, 6, not the first.
Answer: E.

## 3. Common traps

- Negative exponents do not make negative numbers. 2^(-3) = 1/8.
- -x^2 is not (-x)^2. The first is always <= 0, the second is always >= 0.
- Forgetting the negative root: x^2 = 25 gives x = 5 or x = -5. But sqrt(25) is only 5.
- Adding where no rule exists: 2^3 + 2^4 is not 2^7, and sqrt(a) + sqrt(b) is not sqrt(a + b).
- Assuming powers make numbers bigger. For 0 < x < 1 they make them smaller, and for negatives the sign may flip.
- Forgetting 0 and 1. x^2 = x for both, which often turns an apparent A or B into D.
- (2^3)^2 = 2^6 but 2^(3^2) = 2^9. Read the brackets.
- Changing base carelessly: 9^(x+1) = 3^(2x+2), not 3^(2x+1).
- Dividing both sides of an inequality by a power of x with unknown sign. x^3 > x^2 does not simply mean x > 1 until you note x^2 > 0, which also needs x not equal to 0.
- The on-screen calculator shows only 8 digits. Large powers such as 2^60 need exponent rules, not the calculator.

## 5. Answers and solutions

**Answer key:** 1 B, 2 A, 3 C, 4 C, 5 3, 6 D, 7 B, 8 A B D, 9 E, 10 A, 11 C, 12 B, 13 A, 14 15, 15 D, 16 A B D E, 17 D, 18 A, 19 B, 20 B E F, 21 B, 22 B, 23 24, 24 A C E, 25 B

**1. B.** Exponents: 5 + 3 - 6 = 2. 2^2 = 4.

**2. A.** (-3)^4 = 81. -3^4 = -(3^4) = -81.

**3. C.** 72 = 36 * 2, so sqrt(72) = 6 sqrt(2). Check: 6^2 * 2 = 72.

**4. C.** 8^(2/3) = (cube root of 8)^2 = 2^2 = 4. 16^(1/2) = 4.

**5. 3.** 243 = 3^5. So x + 2 = 5 and x = 3.

**6. D.** 4^(3/2) = (sqrt(4))^3 = 8. The negative exponent flips it: 1/8.

**7. B.** For a number between 0 and 1, each extra power makes it smaller. x = 1/2: 1/8 < 1/4. In general x^3 = x^2 * x and x < 1.

**8. A, B, D.** 6^4 = 1,296. (A) (2 * 3)^4 = 6^4. (B) 36^2 = (6^2)^2 = 6^4. (C) 36 + 36 = 72. (D) (12/2)^4 = 6^4. (E) 3^8 = 6,561.

**9. E.** 3.6/9 = 0.4. 10^5 / 10^(-2) = 10^7. 0.4 * 10^7 = 4 * 10^6.

**10. A.** sqrt(50) + sqrt(18) = 5 sqrt(2) + 3 sqrt(2) = 8 sqrt(2), about 11.3. sqrt(68) is about 8.2. The trap is adding under the root to get equal.

**11. C.** 3^(2x) = 3^(3x - 6). So 2x = 3x - 6 and x = 6. Check: 9^6 = 531,441 = 27^4.

**12. B.** 2^30 = (2^3)^10 = 8^10. 3^20 = (3^2)^10 = 9^10. 9^10 is greater.

**13. A.** Multiply top and bottom by 3 + sqrt(3): 6(3 + sqrt(3))/(9 - 3) = 3 + sqrt(3). Estimate check: 6/1.27 = 4.73 and 3 + 1.73 = 4.73.

**14. 15.** 10!/8! = 10 * 9 = 90. 3! = 6. 90/6 = 15.

**15. D.** x = 1: both are 1, equal. x = 2: 1/4 < 4, B greater. x = 1/2: 4 > 1/4, A greater.

**16. A, B, D, E.** Test x = -1/2. (A) 1/4 > -1/2, true (positive vs negative). (B) -1/8 > -1/2, true. (C) -1/8 > 1/4, false. (D) 1/x = -2 < -1/2, true. (E) 1/16 < 1/4, true. (F) 1/8 > 1/4, false. Each true statement holds for the whole interval: x^3 = x * x^2 with 0 < x^2 < 1 pulls x toward 0, 1/x is below -1, and x^4 = x^2 * x^2 with x^2 < 1.

**17. D.** 3^45: 45 = 4*11 + 1, first in the cycle 3, 9, 7, 1, so 3. 8^22: 22 = 4*5 + 2, second in the cycle 8, 4, 2, 6, so 4. 3 + 4 = 7.

**18. A.** (sqrt(7) + sqrt(3))^2 = 7 + 3 + 2 sqrt(21) = 10 + 2 sqrt(21). Compare 2 sqrt(21) with 9: square both, 84 > 81. So A is greater than 19. (It is about 19.17.)

**19. B.** 2^(x+3) = 8 * 2^x. So 8 * 2^x - 2^x = 7 * 2^x = 112, 2^x = 16, x = 4. Back-solving works too: 2^7 - 2^4 = 128 - 16 = 112.

**20. B, E, F.** 10^(-3) = 0.001 = 1/1,000. (A) 1/512, larger. (B) 1/1,024, smaller. (C) exactly 0.001, equal, so not less. (D) 1/625, larger. (E) 1/2,187, smaller. (F) 0.0009, smaller.

**21. B.** Pair the 5s with 2s: 2^20 * 5^17 = 2^3 * (2^17 * 5^17) = 8 * 10^17. That is an 8 followed by 17 zeros: 18 digits.

**22. B.** Rationalise each difference. A = 1/(sqrt(x + 1) + sqrt(x)). B = 1/(sqrt(x) + sqrt(x - 1)). A has the larger denominator, so A is smaller. Check with x = 4: A = 0.236, B = 0.268. Square roots grow more slowly as x grows.

**23. 24.** The left side is 4 * 4^x = 4^(x+1) = 2^(2x+2). So 2x + 2 = 50 and x = 24.

**24. A, C, E.** 48n = 16 * 3n, so sqrt(48n) = 4 sqrt(3n). 3n must be a perfect square. n = 3: 9, yes (sqrt(144) = 12). n = 6: 18, no. n = 12: 36, yes (24). n = 18: 54, no. n = 27: 81, yes (36). n = 36: 108, no.

**25. B.** Call the expression E. It is positive. E^2 = (11 + 6 sqrt(2)) + (11 - 6 sqrt(2)) - 2 sqrt(121 - 72) = 22 - 2 * 7 = 8. So E = sqrt(8) = 2 sqrt(2). Other route: 11 + 6 sqrt(2) = (3 + sqrt(2))^2, so E = (3 + sqrt(2)) - (3 - sqrt(2)).
