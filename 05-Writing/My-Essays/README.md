# My GRE essays

Use `Essay-1.md` through `Essay-4.md` for the four timed essays in the schedule.

Before each attempt:

1. Choose a prompt from the [official ETS Issue pool](https://www.ets.org/pdfs/gre/issue-pool.pdf).
2. Copy the complete statement and its specific instruction into the file.
3. Set a 30-minute timer and turn off spelling/grammar assistance.
4. Write only inside the “Timed response” section.
5. After time expires, complete `../03-Essay-Scorecard.md` and record the top lesson below the response.

Keep the original timed response intact. If you revise it, add the revision under a separate heading so you can compare them.
