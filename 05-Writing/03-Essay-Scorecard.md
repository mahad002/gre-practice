## Rubric check

Rate each item 0, 1 or 2: **0 = missing/serious weakness, 1 = adequate, 2 = strong**.

| Criterion | 0–2 | Evidence from the essay | One revision |
|---|---:|---|---|
| Directly follows the specific instruction | | | |
| Clear, qualified position | | | |
| Reasons are logically developed | | | |
| Examples are specific and explained | | | |
| Complexity/counterpoint is handled | | | |
| Paragraphs and transitions guide the reader | | | |
| Sentences are varied and precise | | | |
| Grammar and mechanics rarely distract | | | |

The total is useful only for tracking your own trend; do not convert it mechanically to the ETS 0–6 scale.

## Revision drill

After scoring:

1. Rewrite the thesis so it answers the exact instruction.
2. Choose the weakest body paragraph and add the missing explanation between example and claim.
3. Correct the three most important language errors.
4. Write one reusable lesson in `06-Practice-Tests/Error-Log.md` under AW.

Compare your work with the [official ETS Issue scoring guide](https://www.ets.org/gre/test-takers/general-test/prepare/content/analytical-writing/scoring.html). An AI or human tutor can help, but only ETS reports an official score.
